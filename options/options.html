Monitor for MyEpisodes

One API key connects the extension to your account.

The key is what the extension runs on: every tab from Old Episodes through This Week, the toolbar badge, and marking an episode acquired or watched. Without it there is almost nothing to show.

Create one on your MyEpisodes API keys page. It needs read scope for the episode lists and write to mark episodes acquired or watched. The key is stored in your browser profile and only ever sent to api.myepisodes.com.

days back

How far back the Old Episodes tab looks, ending two days ago — Yesterday and Today already cover the two most recent days. Default 14.

An independent, unofficial extension. Not affiliated with, endorsed by, or connected to MyEpisodes; it only reads and updates your account through the API key you provide.
