Privacy Policy — Monitor for MyEpisodes

Last updated: September 8, 2026

Monitor for MyEpisodes is an independent, unofficial Chrome extension that shows episodes from your MyEpisodes watchlist in the browser toolbar. It is not affiliated with, endorsed by, or connected to MyEpisodes. This page explains what data the extension handles, where it goes, and what control you have over it.

The short version

  • The extension talks to two servers, both on your behalf and at your direction: api.myepisodes.com (your schedule) and api.tvmaze.com (public show artwork).
  • It has no server of its own. Nothing you do in the extension is sent anywhere except those two APIs.
  • There is no analytics, no advertising, and no tracking of any kind.
  • Your data is never sold or shared with anyone other than the two services above.

What the extension stores

DataWhat it isWhere it's stored
MyEpisodes API key The credential you generate yourself on MyEpisodes' API keys page and paste into the extension's settings. It authenticates every request the extension makes on your behalf. chrome.storage.sync — Chrome's built-in settings sync. It follows your Chrome profile to any machine you're signed into, the same as a bookmark or a saved preference. It is stored as plain text, not encrypted by the extension.
Your episode schedule The Yesterday/Today/Tomorrow/This Week lists fetched from your MyEpisodes account, including each episode's acquired/watched status. chrome.storage.local, cached for at most one day so the popup can open instantly, then refreshed.
Show artwork and network name Looked up from TVmaze using the show identifiers your MyEpisodes list already contains. No personal or account information is sent to TVmaze. chrome.storage.local, cached for up to a week.

What the extension sends, and to whom

  • api.myepisodes.com — every request carries your API key as a bearer token, in the Authorization header only (never in a URL), over HTTPS. This is how the extension reads your schedule and how it writes back when you mark an episode acquired or watched. Only your own account's data is requested.
  • api.tvmaze.com — asked for public show and episode information (network, artwork) using show/episode identifiers. This is an unauthenticated, public API; your API key and no other account information is ever sent to it.

No other network requests are made. The extension has no backend of its own — there is no third-party server, in this project or otherwise, that ever sees your API key or your schedule.

Your control over this data

  • Remove key, in the extension's settings page, deletes the API key from chrome.storage.sync and clears every cached list and the toolbar badge.
  • You can revoke the API key at any time from MyEpisodes' API keys page without changing your MyEpisodes password — this immediately stops the extension (or anything else holding that key) from acting on your account.
  • Uninstalling the extension removes everything Chrome stored for it, including the API key and all cached data.

Children's privacy

Monitor for MyEpisodes is not directed at children and does not knowingly collect information from children.

Changes to this policy

If what the extension collects or where it sends data changes, this page will be updated and the "Last updated" date above will change accordingly.
